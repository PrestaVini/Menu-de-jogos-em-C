Central de Jogos em C

Projeto desenvolvido em linguagem C contendo vários minigames executados diretamente pelo terminal.

O objetivo do projeto foi praticar lógica de programação, organização de código e conceitos fundamentais da linguagem C, como funções, structs, ponteiros, vetores, loops e manipulação de strings.
